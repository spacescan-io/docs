# Wallet Monitor

This guide covers the wallet monitor built into the Spacescan explorer. It tracks an address or public key and sends E-Mail alerts, plus a notification table inside Spacescan.

:::tip Looking for cold-storage monitoring?
**SpaceScan Wallets** ([wallets.spacescan.io](https://wallets.spacescan.io)) is the newer, dedicated product for this — it discovers every address from a master public key automatically and adds per-wallet alert rules. Start with [Watch a cold wallet and get email alerts](../wallet_security/cold_wallet_alerts.md).
:::

:::caution Beta feature
This feature is still in Beta, so expect some rough edges. [Reach the team here for support](https://www.spacescan.io/contact-us).
:::
